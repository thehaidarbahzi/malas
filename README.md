# Malas

Java turn-based RPG with a 5-level campaign, wave-based battles, and special enemy types.

## Gameplay

- Main menu: Start Mission, Inventory, Credits, Exit
- Campaign: Level 1 to Level 5
- Each level contains multiple waves
- Special enemies depend on difficulty:
    - Easy: Shield only
    - Normal: Shield and Medic
    - Hard: Shield, Medic, and Bulldozer
